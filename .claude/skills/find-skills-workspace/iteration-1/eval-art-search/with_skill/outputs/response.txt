Yes! There are a few skills that match "generating art or designs":

**Best matches:**

- `algorithmic-art` — Creates algorithmic/generative art using p5.js with seeded randomness, flow fields, and particle systems. This is the closest match if you want code-driven art generation.
- `canvas-design` — Creates visual designs, posters, and artwork. Great for design outputs (images, layouts, visual compositions).
- `frontend-design` — Guidance for building distinctive, visually compelling UI. Useful if the "design" you need is for a web interface.
- `theme-factory` — Likely generates color themes or design system tokens (no full description, but the name suggests design/branding output).

**How to invoke:**

Type the skill as a slash command in the Claude Code prompt:
- `/algorithmic-art` — for generative/code-based art
- `/canvas-design` — for visual designs and artwork
- `/frontend-design` — for UI design guidance

Or just describe what you want naturally — e.g., "create a generative art piece with flow fields" and Claude will invoke `algorithmic-art`, or "design a poster for my event" and Claude will invoke `canvas-design`.
