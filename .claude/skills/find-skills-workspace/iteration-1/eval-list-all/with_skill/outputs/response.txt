**How to invoke a skill:**

Type a slash command in the Claude Code prompt:
```
/skill-name
```

Examples:
- `/xlsx` — launches the Excel/spreadsheet skill
- `/canvas-design` — launches the visual design skill
- `/code-review` — reviews your current code changes

Or just describe what you need naturally and Claude will invoke the right skill automatically. For example: "can you create a poster?" will trigger `canvas-design`.

---

If you'd like a skill for something that doesn't exist yet, use `/skill-creator` to build a custom one.
